# Tom B. · Portfolio

Portfolio de développeur backend, construit en [Astro](https://astro.build)
avec des îlots [React](https://react.dev) : HTML statique par défaut,
JavaScript seulement là où il y a une vraie interaction (animations GSAP,
scroll Lenis). Le site n'a qu'une page de contenu — pas de données serveur,
pas de formulaire, pas de routing applicatif à faire porter par le client.
